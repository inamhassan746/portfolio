# Inam Ul Hassan — Responsive Food Science Portfolio

## Files
- `index.html` — portfolio content and page structure
- `style.css` — responsive layouts for phones, tablets, laptops, and desktops
- `script.js` — typing animation and mobile navigation
- `profile.jpg` — profile portrait
- `image/` — the eight photographs supplied with the project

## Preview locally
Keep the files and the `image` folder together. Open `index.html` in a browser.

## Publish to GitHub Pages
Upload/commit `index.html`, `style.css`, `script.js`, `profile.jpg`, and the complete `image` folder to the same repository root. Preserve the lowercase folder name `image` and all filenames exactly as provided.

## Photo note
The ZIP supplied for this update does not contain a Chickpea Truffles photo. The card therefore uses a clean placeholder rather than a broken image. Add a real photo later as `image/truffles.jpeg` and update the card in `index.html` if you want it displayed. The supplied photos are shown without forced cropping in their card frames.
